# Moodsteer

Detect the user's mood → steer the model's activations → better next reply.

1. user sends message → 2. detect mood → 3. smooth over turns → 4. map mood → behaviours
→ 5. steer (h += Σ α·v) → 6. generate → 7. log + show

## Run

```bash
# setup (once)
python -m venv .venv && .venv/bin/pip install -r requirements.txt
# laptop without GPU: CPU torch is much smaller
#   .venv/bin/pip install torch --index-url https://download.pytorch.org/whl/cpu && .venv/bin/pip install "transformers>=4.56" accelerate

# 1. build steering vectors (8 axes): data/pairs/*.jsonl → artifacts/vectors/*.pt
.venv/bin/python -m vectors.build            # --regen rewrites the example answers
.venv/bin/python -m vectors.tune             # pick each axis's strength → config.STRENGTH

# 2. chat in the terminal, live view of every step
.venv/bin/python cli.py          # commands: /compare /steer /reset /quit

# laptop CPU: small model
MODEL_ID=Qwen/Qwen2.5-0.5B-Instruct DTYPE=float32 .venv/bin/python -m vectors.build
MODEL_ID=Qwen/Qwen2.5-0.5B-Instruct DTYPE=float32 .venv/bin/python cli.py

# no torch at all
FAKE=1 python cli.py
python tests/smoke.py            # run before every push

# optional: HTTP API + scripted users
.venv/bin/python -m core.server
SERVER=http://localhost:8000 python sim/simulate.py
```

How it works, in activation space:
- **read** (`detector/`): the model reads the conversation and names one dominant mood + intensity 0-10.
  Experimental `probe`: mean hidden state over the user message projected onto mood directions
  (`python -m detector.build`). If no detector can answer: neutral, no steering.
- **write** (`vectors/`): 8 axes with two poles (concise ↔ long, warm ↔ cold, calm ↔ enthusiastic,
  simple ↔ technical, direct ↔ roundabout, cautious ↔ overconfident, structured ↔ freeform,
  accountable ↔ defensive). Contrastive completions: mean hidden state over the answer tokens of a + pole
  answer − a − pole answer to the same question. Added to the residual stream by a forward hook at chat time,
  with signed strength: + toward the first pole, − toward the second. Mood → axes: `config.MAPPING`.
- `data/pairs/` is generated by the model on first build (slow, once). It's plain text: commit it and every
  later build takes seconds. Edit it freely, rebuild.
